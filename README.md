# Задание 1

## Задача 2

### Текст задачи

Человек.

Создайте сущность Человек, которая описывается именем и ростом. 
Необходимо предусмотреть проверку на корректность вводимых данных: имя не может быть пустым 
(в случае пустой строки или пробелов устанавливается значение по умолчанию), 
а рост должен находиться в определенном диапазоне.

### Алгоритм решения

Создается класс Human с закрытыми полями name (строка) и height (целое число), а также соответствующими свойствами с защитой данных.

В сеттере свойства Name выполняется проверка на пустую строку или пробелы с помощью string.IsNullOrWhiteSpace(). Если условие не выполняется, имя получает значение по умолчанию («Петр»). В сеттере свойства Height проверяется, что переданное значение больше нуля, иначе рост устанавливается равным стандартному значению (170).

Переопределяется метод ToString(), возвращающий отформатированную строку с указанием имени и роста.

## Задача 3

### Текст задачи

Имена.

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество. Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

### Алгоритм решения

Создается класс FullName, в котором объявляются закрытые поля lastName, firstName и patronymic, а также свойства с проверкой на null.

Реализуется несколько конструкторов для различных комбинаций параметров (по умолчанию, с одним, двумя или тремя аргументами).

Переопределяется метод ToString(): выполняется проверка каждого поля на наличие данных, после чего непустые параметры последовательно объединяются через пробел.

# Задание 2

## Задача 4

### Текст задачи

Сотрудники и отделы.

Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: "Имя работает в отделе Название, начальник которого Имя". В случае если сотрудник является руководителем отдела, то текстовая форма должна быть "Имя начальник отдела Название".

Необходимо выполнить следующие задачи:

1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен оказаться один и тот же отдел и начальник).

### Алгоритм решения

Создается класс Department, содержащий закрытое строковое поле name, список сотрудников employees типа List<Employee>, а также метод AddEmployee() для регистрации новых сотрудников.   Создается класс Employee с закрытыми полями имени, ссылки на объект Department и должности (position).   В классе Employee переопределяется метод ToString() для динамического формирования текстового представления в зависимости от текущей должности сотрудника.

### Текст задачи

Сотрудники и отделы.

В класс Employee добавляется метод GetDepartmentEmployees(), который выполняет проверку ссылки на отдел (this.department) на null, после чего обращается к свойству Employees соответствующего объекта Department и возвращает полный список всех коллег текущего сотрудника.

## Задача 1

### Текст задачи

Пистолет стреляет

Создайте сущность Пистолет, которая описывается количеством патронов (целое число). Предусмотрите конструкторы с заданным начальным количеством патронов и по умолчанию (5 патронов). Реализуйте метод стрельбы, выводящий «Бах!» и уменьшающий счетчик патронов, либо «Клац!», если патроны закончились.

Реализуется метод Shoot(): при положительном количестве патронов выводится «Бах!» и значение уменьшается на единицу, в противном случае выводится «Клац!».
